# Trucking Compliance Services — Operations Portal

Add multiple photos to a load (cargo, trailer, damage) + view them all.

## Deploy
1. Download this zip, then in Terminal:
   cd ~/Documents/GitHub/trucking-portal && rm -rf operations trucking_ops templates manage.py requirements.txt Procfile README.md && unzip -o ~/Downloads/<THIS-FILE>.zip -d . && echo DONE
2. GitHub Desktop -> Commit -> Push. Test in a private/incognito window.

## New: photos on a load
Open a load (Loads/Dispatch -> the load). There's a new "Photos" section where you
can add AS MANY pictures as you want for that specific load -- cargo, trailer,
seals, damage, anything -- each with an optional caption.
- On a phone the upload opens the CAMERA so a driver/you can snap it on the spot.
- Tap any photo to view it FULL-SIZE and flip through them all (arrows, swipe, or
  keyboard). A counter shows "2 / 5".
- Delete any photo with its Delete button.

This is separate from the documents (Rate Con / POD / BOL still live in the
"Documents & billing" section on the same load). Photos are for proof-of-condition
/ cargo pictures; documents are the paperwork.

Great for claims and disputes -- you have dated photo proof of how the cargo and
trailer looked for each load.
