# Trucking Compliance Services — Operations Portal

Hiring PHASES 1-3: recruiting pipeline + DQF checklist + document review queue.

## Deploy
1. Download this zip, then in Terminal:
   cd ~/Documents/GitHub/trucking-portal && rm -rf operations trucking_ops templates manage.py requirements.txt Procfile README.md && unzip -o ~/Downloads/<THIS-FILE>.zip -d . && echo DONE
2. GitHub Desktop -> Commit -> Push. Test in a private/incognito window.

## PHASE 1 — Recruiting pipeline (sidebar -> Hiring)
Full applicant pipeline (Invited ... Approved for hire ... Active driver),
search, completion %, assign recruiter, tags, notes, status history, and
one-click convert-to-driver. Company-isolated.

## PHASE 2 — Driver Qualification Files (sidebar -> Driver files (DQF))
Per-driver DQF checklist against common FMCSA items (application, CDL, medical,
MVR, annual review, road test, prev-employer safety history, PSP, Clearinghouse,
drug test, ELDT). Shows On file / Missing / Expiring / Expired per item and a
completion %. Fleet overview lists every active driver sorted by completion.
Requirements are SYSTEM DEFAULTS -- your compliance professional confirms which
apply. (Documents are managed in each driver's compliance records.)

## PHASE 3 — Document review queue (sidebar -> Doc review)
Uploaded compliance documents wait in a review queue. Staff can Approve
(marks verified), Reject (with reason), or Request replacement. A file is NOT
"verified" just because it exists -- only after approval. Records who reviewed
it and when.
