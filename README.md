## Deploy
1. Download this zip, then in Terminal:
   cd ~/Documents/GitHub/trucking-portal && rm -rf operations trucking_ops templates manage.py requirements.txt Procfile README.md && unzip -o ~/Downloads/<THIS-FILE>.zip -d . && echo DONE
2. GitHub Desktop -> Commit -> Push. Test in a private/incognito window.

## What changed
The landing page is now LIGHT and user-friendly instead of all dark navy:
- White / soft cream backgrounds (easy on the eyes, easy to read).
- Navy + gold used as ACCENTS (logo, headings, video box, final CTA, footer).
- Colorful feature icon tiles (blue/green/gold/purple/coral/teal) so sections are
  easy to scan and feel friendly.
- Same content and working buttons (Start free trial -> /signup/, Log in -> /login/).

This is the clean, approachable style most SaaS marketing pages use. Everything else
about the page (hero, features, how-it-works, pricing, footer) is unchanged in
structure -- just lighter and friendlier.
