# Trucking Compliance Services — Operations Portal

Attach files in team chat AND in task responses.

## Deploy
1. Download this zip, then in Terminal:
   cd ~/Documents/GitHub/trucking-portal && rm -rf operations trucking_ops templates manage.py requirements.txt Procfile README.md && unzip -o ~/Downloads/<THIS-FILE>.zip -d . && echo DONE
2. GitHub Desktop -> Commit -> Push. Test in a private/incognito window.

## New: file attachments
- TEAM CHAT: there's now a 📎 button in the chat box. Attach a file (POD, rate
  con, photo of damage, etc.) and send it -- with or without a message. Images
  show as a thumbnail; other files show as a tap-to-open link. Everyone in the
  same company sees it (company-private, as always).
- TASKS: when you Respond to a task, you can now attach a file too (📎 next to the
  reply box). Great for sending back a signed doc, a receipt, or a photo as proof
  the task is done.

Files are stored in your cloud (R2), same as all your other documents. Any file
type works.
