How it works
Export your loads from Amazon Relay (or any portal) as a CSV / spreadsheet. The first row should be the column headers. The importer automatically recognizes common columns: Trip / VRID / Load ID, Origin, Destination, Pickup date, Delivery date, Rate, Miles, Deadhead, and Customer. Loads with a reference already in your system are skipped so you never import the same load twice. Columns it doesn't recognize are ignored — nothing breaks.
